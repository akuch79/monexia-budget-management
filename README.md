
# Monexia - Budget Management System

## Project Overview

Monexia is a personal budget management website built using HTML5
and CSS3. It helps individuals monitor their income, expenses,
and financial activities through a simple dashboard.

The project is designed to make personal money management easier.

## Features

- Professional financial dashboard.
- Total balance, income and expense summary cards.
- Add Expense form.
- Expense category dropdown with five categories.
- Expense table with five sample transactions.
- Logo image using HTML img element.
- Embedded YouTube budgeting video.
- Collapsible instructions using details and summary.
- Table hover effects.
- Responsive design for mobile and desktop.
- Advanced CSS selectors.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git and GitHub

## Project Structure

### index.html
This file contains the website structure. It includes the header,
dashboard, expense form, expense table, educational video,
instructions and footer.

### style.css
This file controls the website's design. It contains colors,
layouts, spacing, table styling, hover effects, responsive design
and advanced CSS selectors.

### README.md
This file explains the project, its features, technologies and
how to run the website.

## How to Run the Project

1. Clone or download the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a web browser.
4. Alternatively, use the Live Server extension.
